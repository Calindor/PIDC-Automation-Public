Privacy Policy

Effective date: October 29, 2026.

PIDC Automation is an owner-operated tool for managing a private project catalogue. Its Google OAuth integration is intended for the account owner and is not offered as a public service.

Information accessed

When authorized, the automation can access Google Drive files and Google Sheets, including project descriptions, images, file names, identifiers, and file locations. Because the granted Google Drive and Sheets OAuth scopes are broad, the authorization may technically allow access beyond the PIDC folders and spreadsheet. The automation is designed to operate only on the specified PIDC catalogue and its related project files.

Purpose and processing

The tool reads original images, generates reduced-size image thumbnails, uploads them to the relevant Google Drive project folders, and records associations in the PIDC spreadsheet. It may update project cover selections on the owner's explicit instruction. Originals are intended to remain unchanged.

Where information goes

Project files and catalogue records reside in the owner's Google account. Authorized GitHub Actions jobs may temporarily process file contents in GitHub-hosted runners when creating thumbnails. Automation execution logs may contain diagnostic metadata such as project IDs, file names, request failures, and processing results; they should not contain OAuth secrets or private artwork contents. Credentials are held in restricted Google Drive storage and/or GitHub Actions secrets rather than published website files.

Disclosure and use

PIDC Automation does not sell personal data, use Google data for advertising, or intentionally share project files publicly. Data is passed to Google APIs and GitHub Actions infrastructure only as necessary for the authorized operations. Any additional disclosure is subject to the owner's instructions or legal obligations.

Retention and control

Originals, thumbnails, and catalogue records remain in the owner's Google Drive and Sheets until the owner removes them. Temporary runner data is handled according to GitHub Actions operations and retention settings. The owner can revoke OAuth access through Google Account settings and remove automation credentials from GitHub.

Security

The automation uses OAuth 2.0 and restricted repository secrets. No online service can guarantee absolute security. This public information website does not expose the private PIDC catalogue.

Google API Services

Use and transfer of information received from Google APIs will adhere to the Google API Services User Data Policy, including its Limited Use requirements, as applicable.

Changes and contact

This policy may be updated if the automation changes. Questions about this owner-operated application can be sent to claytonheffernan@gmail.com.
